# My TGS (demo)

A clickable demo of My TGS, an app that drafts a traffic guidance scheme (TGS) and its paperwork for traffic management companies in Victoria. Everything in it is sample data for "Demo Traffic Co".

**Open it:** https://adcam02.github.io/my-tgs/

On a phone the app fills the screen; on a computer it shows in a phone-sized frame. Nothing you enter leaves your device except photos taken in the demo, which are saved to the office's OneDrive when the upload relay is switched on (`docs/config.js`).

This repository holds the built site only (`docs/`). It is published with GitHub Pages from the `docs` folder.
